# RRR Foundation - Interactive Donation Platform

An advanced, high-fidelity frontend web application designed and developed for **RRR Foundation**, focusing on education and digital literacy in rural Bangladesh (Sirajganj & Rajshahi divisions).

## ✨ Key Features
* **Dynamic Content Control:** Complete structural handling of multi-language switching (English & Bangla) across all project descriptions and forms.
* **Micro-Interactions & Animations:** Staggered entrance animations for layout elements on page load, paired with tactile, button-like bounce mechanics on image/card clicks.
* **Smart Donation Gateway:** An app-embedded checkout system that dynamically mirrors payment text based on user tier or custom currency inputs.
* **Front-End Validation:** Instant validation protocols that visually flag faulty transaction structures (short numbers, missing TrxIDs) before submissions.
* **Zero Browser-Native Alerts:** Fully integrated aesthetic confirmation screen with custom animated ticks for a modern user experience.

## 🛠️ Tech Stack Used
* **HTML5:** Semantic architecture for layout and accessibility.
* **CSS3:** Custom variables, grid/flexbox distribution, and custom cubic-bezier transition curves.
* **JavaScript (ES6+):** Complete DOM manipulation, state management for inputs/languages, and lifecycle event handling.
